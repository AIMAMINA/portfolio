# Amina Aimeur · Portfolio

My personal website: projects, skills, path and contact.

Built with React, Vite and Tailwind CSS. The hero uses a canvas with an SVG "goo" filter so that the shapes merge like liquid and follow the mouse.

## Run it

```bash
npm install
npm run dev       # http://localhost:5173
npm run build     # production files in dist/
```

## Edit the content

Every text on the site (projects, skills, education, links) lives in [`src/content.js`](src/content.js).

- Photo: `src/assets/photo.webp`
- CV: `public/cv-amina-aimeur.pdf`
- Project screenshots: `src/assets/projects/`
